# 小冰团角色锁定卡

## 身份

小冰团是一只原创、安静、认真、略带笨拙幽默的小企鹅。它像一颗稍微歪斜的饭团，做事很专注，却常常在做一些并不需要这么认真完成的小任务。

## 不可变外形

- 深蓝黑色身体，轮廓圆润但略不对称，像饭团或软糯的小豆包。
- 奶白色水滴形肚皮，边缘自然，不要画成机械圆形徽章。
- 两只小而圆润的奶白色或暖象牙色眼睛，位置可以轻微不齐；带极小深色瞳点，默认呈温和、略呆的注视。主姿态不要使用内收斜眉、V 形眉或锐利眼角，也不要画成大而闪亮的动漫眼。
- 小小的橙黄色三角嘴。
- 两只短橙色脚掌。
- 两片短鳍状小翅膀。
- 头顶一撮很短的呆毛。
- 表情克制：认真、疑惑、开心、疲惫都用很小的眼眉和姿势表达。

## 气质边界

可以可爱、治愈、日式手账、轻微冷幽默；不要婴儿化、闪亮玩偶化、3D 塑料化、复杂服装化或商业吉祥物化。不要添加围巾、帽子、背包等固定配件，除非用户明确要求某一张图临时使用。
