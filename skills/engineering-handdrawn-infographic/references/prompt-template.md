# 通用生图提示词模板

先替换所有方括号变量，再提交给图像生成工具。标签列表数量必须与 `[数量]` 一致。

```text
Use case: scientific-educational
Asset type: portrait engineering science infographic

创作一张竖版手绘工程科普信息图，主题为《[主题]的组成部分》。

背景是一张暖白色、轻微泛黄的横线笔记本纸，带浅蓝色水平横线。纸张左侧有一条淡红色竖向页边线，保留细腻纸张纤维、轻微扫描颗粒和自然的不均匀感。不要使用纯白数字画布。

页面顶部居中写大号蓝色圆珠笔手写标题“[中文标题]”。标题必须逐字准确，字体瘦长、圆润、整洁，标题下方画一条蓝色手绘下划线。

画面中央放置一个尺寸较大的[设备名称]，采用略微俯视的四分之三透视角度，以[局部打开／剖视／拆解]形式展示内部结构。主体约占页面高度的45%至60%。结构符合真实工程逻辑，装配关系可信，各部件层次分明且容易辨认；不要添加不存在或无法解释的零件。

主体采用精细石墨铅笔工程插画风格：黑灰色细线勾勒，密集排线与交叉排线塑造体积，金属表面有真实的磨砂、反光和机械纹理。整体以灰黑色为主，仅在铜线、线路、冷却液、电缆等有助于识别的部位加入少量克制的黄色、红色、蓝色彩铅点缀。保留自然的手绘线条和轻微不完美感。

在主体四周布置[数量]个编号中文标签。标签全部使用同一种蓝色圆珠笔手写体，文字必须逐字准确，并用纤细的蓝色直线箭头准确指向对应部件。标签不得遮挡设备；箭头不得相互交叉，不得穿过主体后再折返；左右布局均衡，间距舒展，留白自然。编号与下列清单一一对应：

1. [部件名称1]
2. [部件名称2]
3. [部件名称3]
4. [部件名称4]
5. [部件名称5]
6. [部件名称6]
[按实际数量增删，不能保留未替换的占位符]

页面底部用同一种蓝色手写体书写2至3行简短的原理说明，逐字写为：
“[说明文字]”

整体效果像一名工程专业学生精心绘制的课堂笔记：技术准确、细节丰富、写实而有手作感、版式整洁、信息清晰、自然扫描质感。

Constraints:
- 竖版单页完整构图，所有内容位于安全边距内。
- 中文标题、编号、标签和原理说明必须完整、可读、逐字准确。
- 主体设备与箭头端点之间必须有清晰、正确的对应关系。
- 保持真实工程剖视插画，不做儿童卡通、营销海报或装饰性幻想机械。

Avoid:
- 3D CGI、摄影棚产品渲染、矢量扁平图标、粗马克笔、油画、水彩铺满。
- 印刷体标签、英文乱码、重复编号、漏字、错别字、无关文字、水印、Logo。
- 过度鲜艳颜色、霓虹光、赛博朋克、深色背景、纯白无纹理背景。
- 设备过小、标签覆盖主体、箭头交叉、箭头指向空白、零件漂浮或装配关系错误。
```

## 变量填写规则

- `[主题]`：使用设备或系统的通用名称，不堆叠副标题。
- `[局部打开／剖视／拆解]`：只保留一种最能显示部件关系的形式。
- `[部件名称]`：使用短、准确、同一粒度的工程名词；避免一条标签中塞入解释句。
- `[说明文字]`：优先说明输入、转换、输出或流路顺序，不重复标签清单。
