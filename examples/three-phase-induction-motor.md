# 示例：三相异步电动机组成部分图

```text
使用 $engineering-handdrawn-infographic，只给我提示词，不要生成图片：做一张三相异步电动机组成部分的竖版手绘工程科普信息图。

默认采用沿轴向局部剖视，保留真实同轴装配关系和均匀气隙。标签使用：
1. 机座与外壳
2. 定子铁芯
3. 三相定子绕组
4. 鼠笼式转子
5. 转轴
6. 轴承

原理说明写成 3 行：三相交流电流通过定子绕组产生旋转磁场；旋转磁场在鼠笼式转子中感应电流并产生电磁转矩；转子以略低于同步转速的速度旋转，经转轴输出机械能。
```

这个示例用于验证 Skill 能否保留定子、转子、绕组、转轴、轴承、同轴关系和均匀气隙等工程约束。
